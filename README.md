# 相談会ナビ(talk-navi)

オンラインの相談会・勉強会・登壇で画面共有して、参加者に **「全体の流れ」「今どこを話しているか」「要点3つ」** を一目で見せる進行画面です。

話す中身は Markdown のノート1枚に書くだけ。ノートを書き換えれば画面も変わります。

## できること

| 機能 | 中身 |
|---|---|
| 進行ナビ | 話題の地図・今の話題・要点3つ・残り時間を1枚で表示。→ ← で進む・戻る |
| その場で直す | E キーで、画面の文字をクリックして直せる。約1秒後にノートへ自動保存 |
| 話す人だけのメモ | N キーで自分用のメモ(ノートの `> メモ:` 行)。画面には出ない |
| 見せる画面の切り替え | 要点ごとに見せる URL を書いておくと、札を押すだけでデモ用の Chrome の窓がそのタブへ切り替わる |
| コピーできる指示文 | ノートの `📋` 行が、C キーで開く窓に「コピー」ボタン付きで並ぶ。参加者に配る指示文に |
| 見た目4種 | リゾート・夜・黒板・白。T キーか「🎨 見た目」ボタンで切り替え |
| キャラ | 今の要点を指さすキャラと、喜ぶキャラが出る(ノートの先頭に `chara: off` で消せる) |

## 動く環境

- **Windows 10 / 11**(画面の切り替えに Windows の仕組みを使っています)
- **Google Chrome**
- **Python 3.10 以上** と、画像を扱う部品 Pillow

インターネットには接続しません。自分のPCの中だけ(127.0.0.1:5417)で動きます。

## 入れ方

1. 緑の **Code** ボタン → **Download ZIP** で落として、好きな場所にすべて展開する
2. Python が無ければ https://www.python.org/downloads/ から入れる(入れる時に「Add python.exe to PATH」にチェック)
3. 展開したフォルダを開き、アドレス欄に `cmd` と打って Enter → 黒い窓が開くので、次の2行を1行ずつ貼って Enter

```
pip install -r requirements.txt
```

```
python make_shortcut.py
```

4. デスクトップに「相談会ナビ」のアイコンができます。ダブルクリックで起動

最初は `notes` フォルダの見本のノート(第1回 相談会(見本))が一覧に出ます。

### ノートの置き場を変えたい時(Obsidian の保管庫など)

`config.example.json` を写して `config.json` という名前にし、中を書き換えます。

```json
{
  "notes_dir": "C:/Users/あなたの名前/Documents/相談会",
  "trash_dir": "",
  "series": "相談会"
}
```

| 項目 | 意味 |
|---|---|
| notes_dir | ノートを置くフォルダ。空なら、このフォルダの `notes` |
| trash_dir | 一覧の「消す」で移す先。空なら `notes_dir` の中の `.trash`。Obsidian なら保管庫の `.trash` を指すと、Obsidian のごみ箱から戻せる |
| series | 「＋新しい回」で付く題名の後ろ(第N回 〇〇) |

書き換えたら、一覧の「終了」→ アイコンをダブルクリックで起動し直すと効きます。

## ノートの書き方

```markdown
---
type: talk_navi
date: 2026-11-07
title: 第1回 相談会
start: "8:00"
end: "9:30"
theme: resort
---

## オープニング | 10
- 今日のゴール: 明日試せることを1つ持ち帰る
- 話題は2つ + 相談タイム
> メモ: ここは画面に出ない。N キーで自分だけ見る

## 話題1 | 20
- 結論
- 中身
  - 🔗 ChatGPT https://chatgpt.com/
- 実例
🔗 話題全体で見せる画面 https://claude.ai/
📋 配る指示文の名前 | ここに書いた1行がコピーできる
```

| 書き方 | 意味 |
|---|---|
| `## 話題 | 分` | 話題と、使う分 |
| `- 要点` | 要点(1話題3つまでが見やすい) |
| 要点の下に字下げした `  - 🔗 名前 URL` | その要点で見せる画面 |
| 字下げ無しの `🔗 名前 URL` | 話題全体で見せる画面 |
| `📋 名前 | 文` | コピーできる指示文 |
| `> メモ:` | 話す人だけのメモ(画面には出ない) |
| `%%` で始まる行 | 画面に出ない書き込み |
| 先頭の `theme` | resort / dark / kokuban / shiro |

ノートは一覧の「編集」か、進行ナビの E キーでも直せます。完全な見本は `notes/sample_dai1kai_navi.md`。

## 進行ナビのキー

| キー | 動き |
|---|---|
| → / ← | 次へ / 戻る |
| ↓ / ↑ | 次の話題 / 前の話題 |
| 数字 | その話題へ飛ぶ |
| O | 今の要点の画面をデモの窓に出す |
| C | コピーできる指示文の窓 |
| N | 自分用のメモ |
| E | その場で直す |
| T | 見た目を切り替える |
| M | 常に手前に出る小さな帯(ミニ帯) |
| F | 全画面 |
| L | 今日見せる画面の一覧 |
| R | 話題ごとに実際にかかった時間 |
| H | 操作の一覧 |
| Q | 回の一覧へ戻る |

画面の下の帯にも同じボタンがあります。

## 外し方

1. 一覧の「終了」で止める
2. デスクトップの「相談会ナビ」アイコンを消す
3. 展開したフォルダを消す

レジストリや Windows の設定は触っていません。自分で書いたノートは `notes`(または `config.json` の場所)にあるので、消す前に要る物は写しておいてください。
Pillow も外す時は、黒い窓で `pip uninstall pillow`。

## 安全について

- 外部と通信しません。自分のPCの中だけで動く小さなサーバーです
- 画面を切り替える時だけ、デモ用の Chrome の窓を前に出して Ctrl+番号 のキーを代わりに押します
- PC がロック中は窓を前に出せないので、何もせずに知らせます

## 中身

```
server.py        … アプリ本体(一覧・編集・進行ナビ・保存)
talk_note.py     … ノートの読み書きと、進行ナビの画面の組み立て
template.html    … 進行ナビの画面
home.html / edit.html … 一覧と編集の画面
screens.py       … デモの窓のタブを切り替える
build.py         … コマンドで進行ナビの HTML を1枚作る(python build.py ノート.md --open)
make_shortcut.py … デスクトップにアイコンを置く
cutout.py / icons.py … キャラやアイコンの絵を緑の背景から切り抜く道具(使わなくても動く)
assets/          … キャラとボタンの絵
notes/           … ノートの置き場(見本入り)
```
